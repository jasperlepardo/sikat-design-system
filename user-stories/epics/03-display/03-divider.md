# Divider

**Epic:** Display
**Component:** Divider

---

## Basic Rendering

### User Story

As a developer consuming Sikat,
I want to render a horizontal divider line between sections of content,
so that I can create visual separation without relying on spacing alone.

### Acceptance Criteria

- [ ] Divider renders an `<hr>` element with Sikat's border styling
- [ ] Divider color adapts to the active theme (light/dark)
- [ ] Divider spans the full width of its container by default

### Controls

| Control | Type | Options                              | Default |
| ------- | ---- | ------------------------------------ | ------- |
| —       | —    | Extends all native `<hr>` attributes | —       |
